# 관통 프로젝트 가이드

> :pencil2: 확정된 일정 및 내용에 따라 가이드 보강 예정 



## 1. 페어

- 기본 : 주제별 2인 1팀
- 페어 고정일 : 기획 PJT(`일정은 추후 안내`)부터 고정됨
- 고정 전까지 매 주 새로운 팀원과 진행하는 것을 권장 



### 1.1 페어 특이사항

- 총원 홀수인 반만 3인 1팀, 한 팀만 허용



---



## 2. 프로젝트 주제의 종류

> 프로젝트 주제는 크게 **지정 주제(도서)**와 **자율 주제**로 나뉩니다.

- **지정 주제 (도서) 팀:**
  
  - **데이터: 안내되는 데이터 셋**을 사용합니다.
  - **핵심 목표:** 주어진 **명세서**에 맞춰 필수 기능을 구현합니다.
  
- **자율 주제 팀:**
  
  - **데이터:** 팀 별로 프로젝트에 사용할 **데이터 셋을 직접 확보**해야 합니다.
  - **핵심 목표:** 팀이 확보한 데이터 셋에 **지정 프로젝트와 동일한 필수 기능**을 적용하여 구현합니다.
  
  > **자율 주제**란?
  >
  > - 지정 주제의 프로젝트의 요구사항은 준수하여 진행하는 프로젝트이며, 도메인(데이터셋)만 변경하여 주제를 변경할 수 있음
  > - 기존 지정 주제에서 너무 어긋한 주제를 기획하는 것은 지양하며, 지정 주제의 기능과 요구사항 범위에서 기획되어야 함



---



## 3. 주차별 주요 이행 사항

- **지정 주제 (도서) 팀:**
  - 선정한 주제의 명세를 매주 수행하고 제출하면 됩니다.
- **자율 주제 팀:**
  - **주간 진행 방식: 반드시 지정 프로젝트 명세의 필수 기능**을 수행하고 제출해야 합니다.
    (단, 자율 데이터 셋이 확보된 팀은 자율 데이터셋으로 필수 기능을 구현할 수 있습니다.)
  - **데이터 셋 확보 (추가 과제):** 프로젝트에 사용할 데이터를 **조별로 자체 확보**해야 합니다.

## 4. 데이터 셋 상세 가이드

### 4.1 합성 데이터 사용 가이드

- **사용 가능성**
  - 합성 데이터 셋을 생성하거나 사용할 수 있으나 **"필요에 따라 제한적으로"** 사용해야 합니다.

- 합성데이터셋 만으로 **서비스 전체**의 데이터셋을 구성할 수 없습니다.
- 서비스의 **"주된 데이터셋"은 반드시 "외부에서" 수집 및 취합**해야 합니다.
- 필요에 따라 합성 데이터셋을 생성하여 주된 데이터셋과 함께 사용할 수 있습니다.
- 합성 데이터셋 또한 제출해야 하며, 제출 시 **생성 방법 및 사용 방법을 함께 기재**해야 합니다.

### 4.2 자율 주제팀 데이터셋 활용 관련 가이드

1. 크롤링 진행 시 필수 확인 사항 (웹사이트 주소 뒤에 `/robots.txt`를 입력하여 확인)
   - 웹 크롤링을 통해 데이터를 수집하려는 경우, 반드시 해당 사이트의 크롤링 허용 정책을 먼저 확인할 것
2. 외부 데이터 활용 시 저작권 및 이용 허락 범위 확인
   - 크롤링 외에 공공데이터나 오픈 데이터를 활용할 때에도  데이터별 이용 허락 조건을 꼼꼼히 확인할 것
