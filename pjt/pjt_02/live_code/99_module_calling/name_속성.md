# 파이썬 `__name__`  — "이 파일, 주인공이야? 부품이야?"

## 1. 개념과 비유 

> **한 줄 정의** 
>
> `__name__` 은 파이썬이 **모든 파일에 자동으로 붙여주는 이름표**입니다. 그리고 그 이름표의 내용은 **"어떻게 실행되었는가"에 따라 바뀝니다.**

### 비유: 영화 촬영장

한 배우가 있습니다. 같은 배우인데, 어느 현장에 가느냐에 따라 역할이 달라집니다.

| 상황                     | 배우의 역할                                 | 파이썬 세계                       |
| ------------------------ | ------------------------------------------- | --------------------------------- |
| **자기 영화** 촬영장     | **주연(`__main__`)** — 카메라가 나를 따라옴 | `python my_module.py` (직접 실행) |
| **남의 영화**에 특별출연 | **조연(`my_module`)** — 이름표 그대로 불림  | `import my_module` (모듈 호출)    |

주연일 때만 하는 일(오프닝 인사, 인터뷰)이 있고, 조연일 때는 그걸 하면 **민폐**입니다. `if __name__ == '__main__':` 은 바로 이 **"내가 주연일 때만 하는 일"** 을 담는 상자입니다.



------



## 2. 동작 원리 & 데이터 흐름 시각화



### CASE A. 직접 실행 — `python my_module.py`

```
[터미널] python my_module.py
     |
     v
┌──────────────────────────────────────────────┐
│ 파이썬 인터프리터                              │
│  1) my_module.py 를 '시작점'으로 인식          │
│  2) __name__  <-  '__main__'  이름표 부착 ⭐   │
└──────────────────────────────────────────────┘
     |
     v
[my_module.py] 위에서 아래로 한 줄씩 실행
     |
     |-- print(...)                 => 실행 ✅
     |-- def greet(): ...           => 정의만 ✅
     |-- if __name__ == '__main__': => '__main__' == '__main__' -> True
     |       print('주연 전용 코드') => 실행 ✅
     v
   종료
```



### CASE B. 모듈 호출 — `python main.py`

```
[터미널] python main.py
     |
     v
[main.py]  __name__  <-  '__main__'   (main.py 가 주연)
     |
     |-- from my_module import greet, add
     |        |
     |        v
     |   ┌───────────────────────────────────────────┐
     |   │ my_module.py 를 '부품'으로 로드            │
     |   │  __name__  <-  'my_module'  ⭐            │
     |   │                                           │
     |   │  print(...)                 => 실행 ✅    │  <- import 만 해도 실행됨!
     |   │  def greet(): ...           => 정의 ✅    │
     |   │  if __name__ == '__main__': => False ❌   │
     |   │      (주연 전용 코드 건너뜀)              │
     |   └───────────────────────────────────────────┘
     |        |
     |        v  (greet, add 라는 부품만 main 에 전달)
     |
     |-- greet('교육생')  => 실행 ✅
     v
   종료
```

> **가장 많이 헷갈리는 포인트** 
>
> `import` 는 "함수만 살짝 가져오는 것"이 아닙니다. **그 파일 전체를 처음부터 끝까지 한 번 실행**한 뒤, 그중 필요한 이름만 꺼내 쓰는 것입니다. 그래서 최상위에 `print()` 가 있으면 **import 만 해도 출력이 튀어나옵니다.** 이걸 막아주는 방패가 바로 `if __name__ == '__main__':` 입니다.



------



## 3. 실행 결과 비교표

| 코드 위치                         | `python my_module.py` (직접 실행) | `python main.py` (모듈 호출) |
| --------------------------------- | --------------------------------- | ---------------------------- |
| `my_module` 의 `__name__` 값      | `'__main__'`                      | `'my_module'`                |
| 최상위 `print()`                  | ✅ 실행                            | ✅ 실행 (import 시점)         |
| `def` 함수 정의                   | ✅ 정의됨                          | ✅ 정의됨                     |
| `if __name__ == '__main__':` 내부 | ✅ **실행**                        | ❌ **건너뜀**                 |

실제 출력:

```text
$ python my_module.py
[my_module] __name__ = __main__
[my_module] 실행 가드 안쪽 실행됨
안녕하세요, SSAFY님!

$ python main.py
[my_module] __name__ = my_module        <- 이름표가 바뀜!
[main] __name__ = __main__
[main] my_module.__name__ = my_module
안녕하세요, 교육생님!
(my_module 의 실행 가드 안쪽은 출력되지 않음)
```

## 4. 그래서 이걸 왜 쓰나요?

> 시험 문법이 아니라 **협업 예절**입니다.

1. **부작용(Side Effect) 차단** 내 파일을 남이 `import` 했을 때, 원치 않는 코드가 멋대로 돌지 않게 막습니다. (예: DB 초기화, 파일 삭제, 무한 루프가 import 만으로 실행되면 사고입니다.)
2. **모듈 자체 테스트 공간** "이 파일 하나만 돌려서 잘 되는지 확인하고 싶다" => 실행 가드 안에 테스트 코드를 넣습니다.
3. **프로그램의 진입점(Entry Point) 표시** 협업자가 파일을 열었을 때 "아, 여기가 시작점이구나"를 한눈에 알 수 있습니다.

## 5. 자주 하는 실수 체크리스트

| ❌ 실수                         | ✅ 올바른 코드                                   |
| ------------------------------ | ----------------------------------------------- |
| `if __name__ == 'main':`       | `if __name__ == '__main__':` (언더바 **2개씩**) |
| `if __name__ = '__main__':`    | `==` 비교 연산자 사용                           |
| `if __name__() == ...`         | `__name__` 은 **변수**이지 함수가 아님          |
| 실행 가드 안에 함수를 **정의** | 함수는 밖에서 정의, 안에서는 **호출**만         |
